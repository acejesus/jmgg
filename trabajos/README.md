# Carpeta de Trabajo

Esta carpeta está destinada para subir tus archivos de trabajo.

## Organización sugerida:
- Crea subcarpetas según el tipo de proyecto o fecha
- Puedes agregar cualquier tipo de archivo aquí

## Cómo subir archivos:
1. Copia o crea tus archivos en esta carpeta
2. Usa git add para agregarlos al staging
3. Haz commit de los cambios
4. Haz push para subirlos a GitHub
